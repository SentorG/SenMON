# Sentor_G | SenMON
**A list of rules for the SenMON challenge!**<br><br>The idea behind the challenge is to run Pokémon (who do not typically have a chance) through Pokémon Platinum in an IronMON-inspired challenge format by giving them a small helping hand at the very beginning. Credit to **@aismallard** for inspiring the project!<br><br>✦ Each Pokémon will receive **FIVE** chances at a run before moving on to the next target (Lab resets).<br>✦ I will be able to give a nature, ability and **ONE** move of my choice to the potential runner.<br>✦ 250 EV cap to spend.<br>✦ Lab battle always has Munchlax (160exp @ level 8).

## SenMON:
| **Rule:** | **Description:** |
|:-:|:-|
| Kaizo-pilled | Most rules from [**Kaizo IronMON**](https://gist.github.com/valiant-code/adb18d248fa0fae7da6b639e2ee8f9c1#kaizo-ironmon-ruleset) apply to the challenge.<br>Any adjustments or changes will be noted below. ⬇️ |
| No Pivot | Level 5 minimum catch rate percentage (guaranteed). |
| One TM Per Split | TM/Levelup Move Sanity active.<br>100% learnable TMs.<br>One ground/gift TM can be taught per split.<br>If the HM friend is holding a TM, this counts as a 'gift'.<br><br>-- SenMON Splits: --<br>Roark, Gardenia, Fantina, Wake (one TM for Maylene AND Wake's badges), Byron, Candice, Galactic, Volkner, E4. |
| Tutor Cope | Fully compatible Move Tutor.<br>Shards now usable! |
| Fixed Rotom | Rotom has had their alternate forms' typing adjusted so that they match Gen 5.<br>Stats still follow Gen 4 code rules for enemy trainers. |
| Chud Berries | Requires damage-reducing and pinch berries to be added to the pool of randomised items. |
| No Perish Song | Perish Song has been removed entirely. |
| EXP Balance | Mythical Pokémon have had their experience yield adjusted. |
| One-shot Dungeons | Only specified locations are considered a dungeon and must be completed without healing at a Pokémon Centre or via an NPC.<br><br>-- Locations: --<br>Oreburgh Mine, Roark's Gym, Valley Windworks, Gardenia's Gym, Eterna Galactic Hideout, Wayward Cave (East), Fantina's Gym, Lost Tower, Pokémon Mansion, Maylene's Gym, Wake's Gym, Fuego Ironworks, Iron Island, Byron's Gym, Candice's Gym, Galactic HQ, Spear Pillar sequence, Volkner's Gym, Victory Road. |
| Diggy Holes | 5 chances at Underground mini game. |
| Fame For One | If a Pokémon wins, they get removed from the list of runners.<br>Winning run information must be stored and displayed publically. |

## Pokémon Stipulations:
| **Rule:** |
|:-|
| Must be at or below 500bst. |
| If the Pokémon exceeds 500bst, it must own a 4x weakness OR learn <4 moves. |
| x4 weakness Pokémon cannot exceed 600bst. |
| x4 weakness Pokémon who exceed 450 cannot have an ability which buffs weakness (Filter, Flash Fire, Water Absorb etc). |
| If I roll an ability which is obsolete for the target Pokémon (e.g. Immunity Arbok or Levitate Charizard), roll again.|
